# Cravin Sim Golf

The first homepage project is one collection of three social videos. Its title is **Cravin Sim Golf** and its service label is **Social Media Content**.

Edit the project text, poster paths and video order in `client/archive/cravin-sim-golf.js`. Website media lives in `web/projects/cravin-sim-golf/`. The same collection also appears on the portfolio page.

The website copies contain the complete videos, encoded as 720 × 1280 H.264 with AAC audio and fast-start metadata. Each is under 11 MB. The much larger original downloads are preserved outside this repository.

The collection is hosted with the website instead of embedding Drive's player. It starts paused and exposes only custom play/pause controls; playing one video pauses the others. Leaving the collection, changing projects or hiding the browser tab stops playback. The three dots change the centre video. Reduced motion skips the entrance animation.

Cravin's project shows factual deliverables rather than illustrative performance statistics. Projects 02 and 03 remain explicitly labelled placeholder studies.
