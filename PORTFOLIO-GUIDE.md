# Adding portfolio work

Open /studio/ on your published site while signed in with the account that owns this Site.

1. Choose a JPG, PNG, WebP, MP4 or WebM file under 20 MB. Upload web-ready copies without private location metadata. Publish only material you have the rights and permissions to share.
2. Add a title and a photo description or video summary/transcript. Videos containing speech require a WebVTT caption file.
3. Save as draft. It stays private.
4. In Your collection, choose Published and Save changes. Select Feature on homepage for the homepage selection. Lower display-order numbers appear first.
5. Choose Archived or Draft to hide a piece. This is reversible and does not erase the original file. Contact the site operator for permanent storage deletion.

No example client work is included. The public portfolio shows an honest empty state until you publish your own pieces. The homepage uses up to three featured pieces, or the first three published pieces when none are featured. Uploaded files use first-party storage, not embedded third-party video players.

The local development preview uses an explicitly local owner identity; production authorization checks the trusted signed-in identity against the configured owner. Local uploads are never deployed.
