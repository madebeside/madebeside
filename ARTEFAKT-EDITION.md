# Made Beside — computational studio edition

Open the local website at http://127.0.0.1:4188/.

This rebuild replaces the prior visual entry with a close Artefakt-led composition: a black micro-grid, responsive character wordmark, sculptural green motion, pixel-reactive photography, oversized typography and full-screen navigation. Work, Services, About, Contact and the four service pages use the same visual system. Existing enquiry storage, portfolio management and policy content remain in place.

Move the pointer across the identity and media. Scroll through the full-width scenes. On Work, drag the photographs or use the arrows. The pause icon beside Menu controls automatic motion and follows navigation within the tab.

If the local preview is no longer running, use `Start Made Beside Preview.cmd` or run the existing `dev` script from this folder. The current source lives on `design/artefakt-rebuild` in an isolated copy of the latest surveyed Made Beside checkout.

Build with the package's `build` script and run its full `test` script. The review and verification limits are recorded in `docs/artefakt-review.md`.
